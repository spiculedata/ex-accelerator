# Tutorials

Step-by-step guides. Each one says what it needs, so you know whether you can follow it on the
[demo data](/guide/demo-data) alone or whether it also needs optional services.

| Tutorial | You will | Needs |
|----------|----------|-------|
| [Your first project](/tutorials/first-project) | Create a project and a workspace, attach datasets and scope the dashboards to them | Core stack + demo data |
| [Explore the analytics dashboards](/tutorials/explore-dashboards) | Read sentiment, topics, languages, engagement, hashtags and phrases | Core stack + demo data |
| [Investigate a question](/tutorials/investigations) | Follow keywords across your posts on a timeline | Core stack + demo data |
| [Build and publish a workflow](/tutorials/workflows) | Assemble a data pipeline visually and publish it | Core stack (running a workflow also needs Dapr) |
| [Schedule a crawl](/tutorials/schedule-a-crawl) | Configure a collection job in Data Capture | Dapr and the crawler |
| [Research in Jupyter](/tutorials/jupyter) | Open the notebook templates against your data | Python and Poetry |

Stuck? See [Troubleshooting and FAQ](/tutorials/troubleshooting) and the [Glossary](/tutorials/glossary).

::: tip Before you start
Follow [Getting started](/guide/getting-started), then load the demo data with
`npm run seed:demo` (see [Try it with demo data](/guide/demo-data)). The screenshots in these
tutorials come from the demo data, and the tutorial walkthrough is regenerated by
`npm run docs:screenshots`, so they stay in step with the app.
:::
